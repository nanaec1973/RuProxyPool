# Дополнительные корневые сертификаты

Сервис проверяет TLS-сертификаты всех сайтов. Часть российских ресурсов использует сертификаты, выпущенные **Russian Trusted Root CA** (НУЦ Минцифры),
которого нет в стандартном наборе доверенных сертификатов. Без него такие сайты будут
считаться недоступными через любой прокси.

Чтобы добавить сертификат:

1. Скачайте корневой сертификат с официального сайта Госуслуг: https://www.gosuslugi.ru/crt
   (файл `russian_trusted_root_ca_pem.crt`).
2. Сверьте отпечаток SHA-256 с опубликованным на официальном сайте:
   `openssl x509 -in russian_trusted_root_ca_pem.crt -noout -fingerprint -sha256`
3. Положите файл в эту папку (`certs/`). Подходят расширения `.pem` и `.crt`.

При запуске в логе появится строка `Добавлен корневой сертификат: ...`.
Путь к папке можно изменить переменной окружения `CERTS_DIR`.

Добавляйте сюда только сертификаты из официальных источников: всё, что лежит в этой
папке, сервис считает доверенным.
