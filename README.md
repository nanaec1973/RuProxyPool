# 🛡️ RuProxyPool — Автоматический сканер и API доступных серверов для ресурсов РФ

Высокоскоростной сервис на **Go** (без внешних зависимостей), который в фоновом режиме собирает тысячи кандидатов прокси-серверов (`HTTP` и `SOCKS5`), параллельно проверяет их пробиваемость к ключевым государственным и инфраструктурным ресурсам РФ и отдает готовые рабочие адреса через **REST API** и **интерактивный веб-дашборд**.

🌐 **Боевой сервер (Live Dashboard & API):**  
👉 **[https://ru-proxy-pool.onrender.com](https://ru-proxy-pool.onrender.com)**

## 🏗 Архитектура проекта

```text
RuProxyPool/
├── main.go         # HTTP-сервер, маршруты REST API, корректная остановка
├── config.go       # Все настройки из переменных окружения
├── security.go     # Фильтр адресов (SSRF), лимиты запросов, токен, заголовки безопасности
├── targets.go      # Целевые ресурсы РФ и структуры данных (ProxyResult)
├── fetcher.go      # Сбор адресов из 31 публичного источника + фильтр по подсетям РФ
├── checker.go      # Проверка прокси: TCP, HTTPS с проверкой сертификатов, SOCKS5 (RFC 1928)
├── geo.go          # Город/провайдер по IP с учётом лимитов бесплатных гео-API
├── pool.go         # Пул живых серверов: статистика стабильности, перепроверки, сохранение на диск
├── static/         # Веб-дашборд (HTML/CSS/JS, встраивается в бинарник)
├── certs/          # Дополнительные корневые сертификаты (см. certs/README.md)
├── main_test.go    # Тесты
├── Dockerfile      # Многоступенчатая сборка, запуск от непривилегированного пользователя
└── go.mod          # Модуль Go (0 внешних зависимостей — только стандартная библиотека)
```

### Как работает цикл сканирования
1. **Сбор кандидатов (`fetcher.go`):** параллельно опрашивает 31 источник (`Proxifly`, `ProxyScrape`, `GeoNode`, `Spys.me`, `Monosans`, `TheSpeedX` и др.). Остаются только публичные IPv4 из российских подсетей (RIPE NCC / IPDeny). Если источник указал протокол, проверяется только он.
2. **TCP-фильтр (`checker.go`):** быстрый TCP-коннект с таймаутом 1,8 с отсеивает неактивные адреса.
3. **Проверка HTTPS:** через прокси (`HTTP CONNECT` или `SOCKS5`) открываются все 8 ресурсов с **проверкой TLS-сертификатов**. Прокси, подменяющие сертификат или содержимое страниц, отсеиваются.
4. **Проверка выхода:** через прокси запрашивается `api.ipify.org`. Прозрачные прокси (сайт видит IP самого сервиса) и прокси, выходящие в интернет не из РФ, отбрасываются.
5. **Стабильность (`pool.go`):** у каждого прокси считается uptime. Один провал не удаляет прокси из пула, после 2 провалов подряд он пропадает из выдачи, после `MAX_FAILS` (по умолчанию 3) удаляется.
6. **Расписание:** полный сбор раз в 10 минут, перепроверка живых раз в 2 минуты, пул сохраняется на диск.

## 🔌 Документация REST API

### 1. Получить один быстрый рабочий сервер (`/api/random`)
Возвращает случайный сервер из топ-25 самых стабильных и быстрых для указанного сайта (прокси с недавними провалами не выдаются). Идеально для автоматической подстановки в парсеры перед запуском.

**Параметры запроса:**
* `target` *(необязательно)* — фильтр по ресурсу (`mosgorsud`, `gosuslugi`, `cbr`, `nalog`, `mos`, `sber`, `rzd`, `ya`).
* `protocol` *(необязательно)* — `http` или `socks5`.
* `format` *(необязательно)* — `json` (по умолчанию) или `txt` (возвращает только строку `IP:Port` или `protocol://IP:Port`).

**Примеры:**
```bash
# Получить один готовый IP:Port для Мосгорсуда простым текстом
curl -s "https://ru-proxy-pool.onrender.com/api/random?target=mosgorsud&format=txt"
# Ответ: 77.221.148.116:10808

# Получить полную карточку случайного сервера для Мосгорсуда в JSON
curl -s "https://ru-proxy-pool.onrender.com/api/random?target=mosgorsud"
```

---

### 2. Получить список всех проверенных серверов (`/api/proxies`)
Возвращает список всех живых серверов, отсортированный по качеству и минимальному пингу до выбранной цели.

**Параметры запроса:**
* `target` *(необязательно)* — фильтр по ресурсу (например, `mosgorsud`).
* `protocol` *(необязательно)* — `http` или `socks5`.
* `limit` *(необязательно)* — ограничение количества записей (например, `limit=20`).
* `format` *(необязательно)* — `json` или `txt` (список `IP:Port` по одному на строку).

**Примеры:**
```bash
# Скачать текстовый список всех живых серверов для Мосгорсуда
curl -s "https://ru-proxy-pool.onrender.com/api/proxies?target=mosgorsud&format=txt"

# Получить JSON со всеми серверами, открывающими Госуслуги
curl -s "https://ru-proxy-pool.onrender.com/api/proxies?target=gosuslugi"
```

### 3. Сводная статистика пула (`/api/stats`)
Возвращает текущее состояние сканера, прогресс проверки и количество живых серверов по каждому ресурсу РФ.

```bash
curl -s "https://ru-proxy-pool.onrender.com/api/stats"
```

---

### 4. Сообщить о нерабочем прокси (`POST /api/report`)
Если парсер получил ошибку через прокси, сообщите об этом. Прокси не удаляется сразу (чтобы пул нельзя было «обнулить» ложными жалобами), а опускается вниз выдачи и внеочередно перепроверяется.

```bash
curl -X POST "https://ru-proxy-pool.onrender.com/api/report?address=185.179.189.248:1080&protocol=socks5"
```

---

### 5. Служебные эндпоинты (нужен `ADMIN_TOKEN`)

`POST /api/scan` (внеочередное сканирование) и `POST /api/proxies/add` (свои адреса на проверку) работают только с токеном. Если переменная `ADMIN_TOKEN` не задана, они отключены.

```bash
# Внеочередное сканирование
curl -X POST -H "Authorization: Bearer $ADMIN_TOKEN" "https://ru-proxy-pool.onrender.com/api/scan"

# Добавить свои адреса (до 1000 за запрос, тело до 256 КБ)
curl -X POST -H "Authorization: Bearer $ADMIN_TOKEN" "https://ru-proxy-pool.onrender.com/api/proxies/add" \
  --data-binary $'31.40.248.2:8080\nsocks5://77.221.148.116:10808'
```

На дашборде токен вводится в поле «Служебные действия» и хранится только в текущей вкладке браузера.

## 💻 Примеры интеграции в ваши проекты

### Интеграция в Go (например, для парсера Мосгорсуда с Selenium / Chrome)

```go
package main

import (
	"encoding/json"
	"fmt"
	"net/http"
	"time"
)

type ProxyItem struct {
	Address  string `json:"address"`
	Protocol string `json:"protocol"`
}

// GetLiveMosgorsudProxy запрашивает у нашего сервиса самый быстрый живой прокси для Мосгорсуда
func GetLiveMosgorsudProxy() (string, error) {
	client := &http.Client{Timeout: 10 * time.Second}
	resp, err := client.Get("https://ru-proxy-pool.onrender.com/api/random?target=mosgorsud")
	if err != nil {
		return "", err
	}
	defer resp.Body.Close()

	var item ProxyItem
	if err := json.NewDecoder(resp.Body).Decode(&item); err != nil {
		return "", err
	}
	// Формат для флага Chrome: "--proxy-server=socks5://77.221.148.116:10808" или "http://..."
	return fmt.Sprintf("%s://%s", item.Protocol, item.Address), nil
}

func main() {
	proxyURL, err := GetLiveMosgorsudProxy()
	if err != nil {
		panic(err)
	}
	fmt.Println("Используем проверенный прокси для Мосгорсуда:", proxyURL)
	// Передаем в ChromeOptions: "--proxy-server=" + proxyURL
}
```

### Интеграция в Python (`requests`)

```python
import requests

# Получаем случайный проверенный прокси для Мосгорсуда
r = requests.get("https://ru-proxy-pool.onrender.com/api/random?target=mosgorsud").json()
proxy_url = f"{r['protocol']}://{r['address']}"

print(f"Подключаемся через {proxy_url}...")
resp = requests.get("https://mos-gorsud.ru", proxies={"http": proxy_url, "https": proxy_url}, timeout=10)
print("Статус Мосгорсуда:", resp.status_code)
```

| `RATE_LIMIT_RPM` | `300` | Запросов в минуту с одного IP к публичному API |
| `ADMIN_RATE_LIMIT_RPM` | `10` | Запросов в минуту к служебным эндпоинтам |

| `MAX_CUSTOM` / `MAX_ADD_PER_CALL` | `5000` / `1000` | Лимиты на пользовательские адреса |
| `CHECK_IP_URL` | `https://api.ipify.org` | Сервис для определения IP выхода прокси |

## 🔐 Безопасность

* **TLS проверяется всегда.** Прокси с подменой сертификата (MITM) в пул не попадают. Для сайтов с сертификатами Минцифры добавьте корневой сертификат в `certs/` (см. [certs/README.md](certs/README.md)).
* **Служебные эндпоинты закрыты токеном**: сравнение за постоянное время, отдельный строгий лимит запросов, только метод `POST`, без CORS.
* **Защита от SSRF**: сервис никогда не подключается к локальным, частным, служебным адресам (`127.0.0.0/8`, `10.0.0.0/8`, `192.168.0.0/16`, `169.254.0.0/16` и др.) и к портам почты/SSH/DNS — даже если такие адреса пришли из источника или от пользователя.
* **Лимиты**: ограничение частоты запросов по IP, размера тела запроса, числа пользовательских адресов; таймауты HTTP-сервера против медленных атак.
* **Дашборд**: строгая Content-Security-Policy, данные выводятся только через `textContent` (без внедрения HTML), запрет встраивания во фреймы.
* **Docker**: сервис работает от непривилегированного пользователя, файл пула создаётся с правами `0600`.
* **Никогда не храните `ADMIN_TOKEN` в коде или в репозитории** — только в переменных окружения (на Render: *Environment → Add Environment Variable*).

> ⚠️ Бесплатные публичные прокси принадлежат неизвестным владельцам. Используйте их только для сбора открытых данных и не передавайте через них логины, пароли и личную информацию.

## 🚀 Локальный запуск и Docker

### Запуск напрямую через Go
```bash
git clone https://github.com/nanaec1973/RuProxyPool.git
cd RuProxyPool
ADMIN_TOKEN=$(openssl rand -hex 32) go run .
```
После запуска откройте в браузере `http://localhost:8080`. Тесты: `go test ./...`

### Сборка и запуск в Docker
```bash
docker build -t ru-proxy-pool .
docker run -d -p 8080:8080 -e ADMIN_TOKEN=ваш_токен \
  -v ru-proxy-pool-data:/app/data --name ru-proxy-pool ru-proxy-pool
```
Том `/app/data` сохраняет пул между перезапусками.

### Render.com
1. В настройках сервиса задайте `ADMIN_TOKEN` (*Environment*).
2. На бесплатном тарифе диск временный: при засыпании и перезапуске сохранённый пул теряется, и первые прокси появляются после первого скана (около минуты). Чтобы пул переживал перезапуски, подключите *Persistent Disk* с точкой монтирования `/app/data`.
