# 🛡️ RuProxyPool

Автоматический высокоскоростной Go-сканер и пул доступных прокси-серверов (HTTP / SOCKS5) для работы с ключевыми ресурсами РФ (**Мосгорсуд, Госуслуги, ЦБ РФ, ФНС, Сбербанк, Мос.ру, РЖД, Яндекс**).

## 🚀 Возможности

- **Многопоточное сканирование (Worker Pool на горутинах):** проверяет тысячи кандидатов за считанные секунды.
- **Двухэтапная фильтрация:**
  1. Сверхбыстрый TCP-пинг для мгновенного отсева недоступных узлов.
  2. Проверка реального прохождения HTTPS-запросов к целевым сайтам РФ.
- **Поддержка HTTP и SOCKS5 из коробки** (чистый Go, 0 внешних зависимостей).
- **Готовое внешнее REST API** для интеграции с парсерами (например, парсером Мосгорсуда).
- **Живой веб-дашборд** с фильтрами по каждому сайту, пингами и прогресс-баром.

## 🔌 API Эндпоинты

| Метод | URL | Описание |
|---|---|---|
| `GET` | `/api/random?target=mosgorsud&format=txt` | Возвращает **один быстрый рабочий `IP:Port`** текстом для Мосгорсуда |
| `GET` | `/api/random?target=mosgorsud` | Возвращает JSON с подробностями случайного быстрого прокси |
| `GET` | `/api/proxies?target=mosgorsud&format=txt` | Список всех проверенных `IP:Port` (по одному на строку) |
| `GET` | `/api/proxies?target=gosuslugi` | JSON-список серверов, открывающих Госуслуги |
| `GET` | `/api/stats` | Текущая статистика пула и прогресс сканирования |
| `POST` | `/api/scan` | Запуск внеочередного цикла сканирования |
| `POST` | `/api/proxies/add` | Добавление собственного списка `IP:Port` на проверку |
| `GET` | `/health` | Проверка работоспособности сервиса (Healthcheck) |
